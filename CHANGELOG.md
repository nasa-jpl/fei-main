# Changelog

All notable changes to this project will be documented in this file. 

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [3.4.3](https://github.jpl.nasa.gov/MIPL/fei-main/releases/tag/3.4.3) - 2023-11-27

### Release of FEI Main 3.4.3 

- Enhancements and fixes in support of FEI client services
- Changes to line terminators and repository settings to support Windows BAT file execution

## [3.4.2](https://github.jpl.nasa.gov/MIPL/fei-main/releases/tag/3.4.2) - 2023-06-06

### Release of FEI Main 3.4.2 

- Enhancements and fixes in support of FEI client services
- Update Log4J to respond to reported 
- Update to JDK Semaphore class to improve performance and fix security issues
- Add name argument for SMTP appender object
- Other fixes and build system updates to support latest release tooling for API inheritance

## [3.2.0](https://github.jpl.nasa.gov/MIPL/fei-main/releases/tag/3.2.0) - 2021-07-26

### Release of FEI Main 3.2.0 

- Enhancements and fixes in support of FEI client services
- Javamail missing client fix
- Correct issue where queue and subscriber list are out of sync and files cannot be purged
- TransactionManager getFile() function now returns the full path
- Various CWE fixes
